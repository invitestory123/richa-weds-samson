  - 14 Dec 4:00 PM: The Sacred Pheras @ The Lawn (Anything but Red / Maroon) · Invitees: Mr. Mukesh Arora, Mrs. Vishakha Arora, Mr. Satyapal Arora, Mrs. Krishana Arora, Mr. (Late) Vijay Hadkar & Mrs. (Late) Vaijayanti Hadkar
